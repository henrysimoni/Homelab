

\# IT Infrastructure Homelab



A hands-on homelab using VMware Workstation to develop practical skills in Windows Server, Active Directory, networking, automation, and cloud administration.



\## Goals

\- Build and manage a Windows Server environment.

\- Configure Active Directory, DNS, DHCP, and Group Policy.

\- Practice PowerShell automation and troubleshooting.

\- Explore Microsoft Azure, Entra ID, and Intune.



\## Lab Environment

\- \*\*Hypervisor:\*\* VMware Workstation Pro

\- \*\*Domain Controller:\*\* DC01 — Windows Server

\- \*\*Client:\*\* CLIENT01 — Windows 11 Pro

\- \*\*Domain:\*\* `ad.lab`

\- \*\*Network:\*\* VMware NAT (`192.168.1.0/24`)
